# 连续双语阅读窗

这个改版适用于 Windows 11 22H2 及以上。默认识别来自 Windows 实时字幕，翻译继续使用原项目支持的服务。本测试分支另提供可选的本地说话人区分模式，详见 [说话人区分](说话人区分.md)。

## 使用

1. 解压自包含版本，运行 LiveCaptionsTranslator.exe。首次使用按照原项目说明下载 Windows 实时字幕语言包，并将识别语言设为英语。
2. 在主窗口的 Setting 中选择翻译服务和中文目标语言。原有 API 配置可继续使用。
3. 播放 Zoom 或其他应用的语音。阅读窗会自动打开，按“时间 → 英文 → 中文”显示；新内容从底部追加。
4. 用“每条长度”选择短、适中或长，默认适中；用“停顿分段”选择 2、3、5、8、12 秒，默认 3 秒。短句在所选停顿时间内继续合并，长文字自然换行。
5. 向上滚动查看历史。阅读旧内容时，新字幕继续保存；点击“回到最新”恢复跟随。
   快捷键：Ctrl+Home 跳到当前已加载记录顶部，Ctrl+End 回到最新，Ctrl+鼠标滚轮调整字号。
6. 主窗口的“连续阅读”按钮打开或关闭阅读窗。关闭阅读窗不会停止记录；关闭主窗口才退出程序。

窗口支持置顶、字号、拖动和缩放，并保存这些设置、段落长度和停顿时间。文字可以选择复制，“复制双语”复制整段原文与译文。“导出 CSV”导出全部历史，每个双语段落一行，使用带 BOM 的 UTF-8 编码。

## 自然段怎样形成

| 每条长度 | 开始优先分段 | 无句末、无停顿时的长度上限 |
| --- | --- | --- |
| 短 | 30 个英文词 | 约 60 词 |
| 适中（默认） | 40 个英文词 | 约 80 词 |
| 长 | 60 个英文词 | 约 120 词 |

- 不到左栏长度，普通句号及短于所选停顿时间的暂停继续合并。默认 3 秒时，1–2 秒短暂停顿不会单独分条。
- 达到左栏长度，优先在完整句末或约 1.5 秒字幕停顿处分段。
- 一直说且没有标点时，在右栏长度附近按词边界另起一段。
- 原文达到“停顿分段”所选时间没有更新后，下一段新内容另起一条，即使上一条还很短。可选 2、3、5、8、12 秒，默认 3 秒。译文返回和窗口滚动不会重置这个计时。
- 调整长度或停顿时间影响后续内容，已显示的段落不会重新拆排。切换翻译服务、目标语言或仅记录模式后，新内容进入新段落。

这些时间测量的是字幕文字更新，不是直接测量声音中的静音。识别延迟可能影响分段。“一条”指便于阅读的双语块，长文仍会换行；普通 Windows 字幕模式没有说话人身份，不能保证每条恰好对应一个人。可选的本地模式依据音频区分匿名说话人，仍可能误判。

内部仍按句子和小片段翻译，片段逐一补到所属段落中。新增片段不会清空其他已完成的中文；某片段失败时，其他译文仍保留，并提示部分失败。识别修订按连续词序回填原片段；系统补加句号、修改撇号或滚动字幕时，不会因为句子数量变化而重新追加后面的旧句。过期结果不能覆盖新版本。长度上限以新内容分配时的词边界为准，识别修订保持既有段落归属。

## 保存位置与升级

正常启动时，setting.json 和 translation_history.db 位于程序所在目录。请放在可写目录中。升级前退出旧版并备份这两个文件，再替换程序；同目录的新版本会继续使用原设置与历史。运行中的数据库还可能有 -wal 和 -shm 文件，备份时先退出程序。

本次在历史表中增加可空的 ParagraphId 列；已有 Version 用于拒绝过期译文。新段落以首片段的 ID 为组 ID，与原文一起写入。旧记录按原来的条目和段落读取，不会追溯合并；已经保存的重复历史不会自动删改。修复对之后新识别的字幕生效。原 CSV 五列不变：Timestamp、SourceText、TranslatedText、TargetLanguage、ApiUsed。

阅读窗先载入最近 200 个完整段落，上翻每次加载更早的 100 个，不会把一个段落拆到两页。关闭重开及重启都能查看已保存记录。退出前尚未返回的译文不会在下次启动时自动重试，英文仍保留。原主窗口历史页继续提供内部片段列表，连续阅读窗和 CSV 使用段落视图。

## 限制

Windows 没有提供发言人身份；完全相同且没有任何字幕变化或清空信号的连续音频，不能仅凭文字区分。软件本身免费；在线翻译服务的可用性、额度和费用取决于所选服务，本次没有新增云服务。

界面参考 SonicMeet 的“按语言成块”展示；这里的分段规则是本项目自行实现的，不代表其内部算法。[SonicMeet 官方说明](https://sonicmeet.app/help/captions-and-translation)

## 开发与验证

使用 .NET 8 SDK：

```powershell
dotnet build LiveCaptionsTranslator.csproj -c Release
dotnet run --project tests/Reader.Tests/Reader.Tests.csproj -c Release
dotnet publish LiveCaptionsTranslator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/speaker-win-x64
```

测试覆盖自然段长度与停顿、修订、重复发言、滚动字幕、独立片段翻译、乱序及失败、服务切换、设置保存、旧库迁移、段落分页及 CSV。

用于界面检查的演示参数：

```powershell
.\LiveCaptionsTranslator.exe --reader-demo
```

演示不采集音频、不调用翻译服务。默认写入程序旁的 demo-data；也可用 --data-dir=绝对路径指定独立测试目录。正式会议直接启动程序，不附加演示参数。

本机自动测试和真实音频验证见 [验收记录](验收记录.md)。
