# 连续双语阅读窗

这个改版适用于 Windows 11 22H2 及以上。识别来自 Windows 实时字幕，翻译继续使用原项目支持的服务。

## 使用

1. 解压自包含版本，运行 LiveCaptionsTranslator.exe。首次使用按照原项目说明下载 Windows 实时字幕语言包，并将识别语言设为英语。
2. 在主窗口的 Setting 中选择翻译服务和中文目标语言。原有 API 配置可继续使用。
3. 播放 Zoom 或其他应用的语音。阅读窗会自动打开，每条显示时间、英文和对应中文；正在识别的句子在原位置更新。
4. 向上滚动可查看历史。阅读旧内容时，新字幕继续保存；点击“回到最新”恢复跟随。
   快捷键：Ctrl+Home 跳到当前已加载记录顶部，Ctrl+End 回到最新，Ctrl+鼠标滚轮调整字号。
5. “连续阅读”按钮打开或关闭阅读窗。关闭阅读窗不会停止记录；关闭主窗口才退出程序。

窗口支持置顶、调整字号、拖动和缩放，并保存这些设置。文字可以选择复制，每条右侧可以复制整条双语记录。“导出 CSV”导出全部历史，按时间顺序排列，并使用带 BOM 的 UTF-8 编码。

## 保存位置与兼容性

正常启动时，setting.json 和 translation_history.db 位于程序所在目录。请把程序放在可写目录中。升级前退出旧版并备份这两个文件；迁移原版历史时，将它们复制到改版程序目录。退出前尚未返回的译文不会在下次启动时自动重试，英文仍保留。运行中的数据库还可能有 -wal 和 -shm 文件，备份时先退出程序。

原历史表、字段和 CSV 列保持兼容。改版为历史表增加 Version 列，防止过期结果覆盖新修订。记录在英文出现时即写入，翻译完成后更新同一 ID；失败时仍保留英文。

阅读窗先载入最近 200 条，上翻每次加载更早的 100 条，不受原版上下文卡片条数限制。关闭重开及重启都能查看已保存记录。

## 分段与限制

每段英文与对应译文成对显示，不标姓名或说话人 A/B。分段来自 Windows 实时字幕文本和标点，不是音频说话人分离。如果 Windows 没有输出标点，字幕稳定约 1.2 秒后会按停顿分段；识别修订仍在原条目内更新。长句会自然换行。Windows 没有提供发言人身份；完全相同且没有任何文本变化或清空信号的连续音频，不能仅凭字幕文本区分。

软件本身免费；在线翻译服务的可用性、额度和费用取决于所选服务。本次改动没有新增云服务。

## 开发与验证

使用 .NET 8 SDK：

```powershell
dotnet build LiveCaptionsTranslator.csproj -c Release
dotnet run --project tests/Reader.Tests/Reader.Tests.csproj -c Release
dotnet publish LiveCaptionsTranslator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/win-x64
```

测试程序覆盖逐句配对、修订、相同文字的独立发言、滚动字幕、乱序结果、失败保存、旧数据库、分页和 CSV。

用于界面检查的演示参数（示例数据与正常记录分开）：

```powershell
.\LiveCaptionsTranslator.exe --reader-demo
```

演示不采集音频、不调用翻译服务。默认写入程序旁的 demo-data；也可通过 --data-dir=绝对路径指定独立测试目录。正式会议请直接启动程序，不附加演示参数。

本机的自动测试和真实音频验证见 [验收记录](验收记录.md)。
